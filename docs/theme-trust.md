# Theme: Trust (Group B)

## Concept
A sharp, high-contrast fintech aesthetic. Inspired by Current and Upside. Focus on reliability and currency.

## Tokens
- **Background**: `Stark White (#ffffff)`
- **Foreground**: `Dark Navy (#020617)`
- **Primary**: `Deep Teal (#0f5a4e)`
- **Border Radius**: `0.25rem` (Sharp, disciplined)
- **Font**: `Space Grotesk` (Headings), `Inter` (Body)

## Styling Rules
- **Shadows**: Crisp, defined shadows or borders.
- **Micro-interactions**: Snappy, instant transitions.
- **Layout**: Grid-aligned, dense data presentation.

## Usage
Select "Trust B" in the floating toggle.
