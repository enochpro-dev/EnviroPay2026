# Theme: Eco (Group A)

## Concept
Offers a calm, future-forward sustainability vibe. Inspired by Bower and SmartDRS.

## Tokens
- **Background**: `Mint White (#f8faf9)`
- **Foreground**: `Deep Forest (#1c2e26)`
- **Primary**: `Calm Green (#2d8a6e)`
- **Border Radius**: `1rem` (Highly rounded)
- **Font**: `Sora` (Headings), `Inter` (Body)

## Styling Rules
- **Shadows**: Soft, diffused shadows.
- **Micro-interactions**: Gentle pulsing on active states.
- **Layout**: Generous whitespace, organic feel.

## Usage
Select "Eco A" in the floating toggle.
