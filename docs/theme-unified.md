# Theme: Unified (Group C)

## Concept
The synthesis of Eco warmth and Trust clarity. The target identity for PfandPay.

## Tokens
- **Background**: `Soft White (#fdfefd)`
- **Foreground**: `Slate 800 (#1e293b)`
- **Primary**: `PfandPay Green (#1a7a5e)`
- **Border Radius**: `0.75rem` (Modern, balanced)
- **Font**: `Sora` (Headings), `Inter` (Body)

## Styling Rules
- **Shadows**: Balanced, premium float.
- **Micro-interactions**: Smooth, professional.
- **Layout**: Best of both worlds—readable but friendly.

## Usage
Select "Unified C" in the floating toggle. Default on load.
